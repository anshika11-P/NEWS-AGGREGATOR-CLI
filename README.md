# News Aggregator CLI

## Description

News Aggregator CLI is a Python-based project
that collects news from multiple RSS sources.

Users can search, filter, save and export news.

## Features

1. Fetch Latest News
2. Search News by Keyword
3. Filter News by Source
4. Filter News by Date
5. Store News in SQLite
6. Save News in JSON
7. Remove Duplicate News
8. Export News to CSV
9. Export News to Excel

## Technologies Used

- Python
- Requests
- SQLite
- JSON
- Pandas
- OpenPyXL
- RSS Feeds

## Installation

pip install -r requirements.txt

## Run Project

python main.py
